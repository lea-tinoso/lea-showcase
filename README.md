# lea-showcase

Lea Tinoso's personal portfolio. It shows how I think and work as a software engineer building with Claude Code, rather than only listing a tech stack.

## What's here

A single static page, `index.html`, with no build step. Open it in a browser, or serve the folder with any static host (GitHub Pages, Vercel, Netlify).

## Design

The style is **neo-brutalism**, the look Gumroad uses: thick black outlines, flat bright colours (pink, yellow, teal) and hard offset shadows, set in Bricolage Grotesque. The hero layout, with the name split around a cartoon portrait, comes from the "name as a monument" direction in [taste-skill](https://github.com/lea-tinoso/taste-skill).

## Sections

1. **Hero**: name, cartoon portrait with an Instagram-style note for the current side quest, one-line intro.
2. **My loop**: Explore, Plan, Build, Verify, and what I ask Claude at each step.
3. **Case file**: how this site was built, from the first prompt to the decisions behind it.
4. **Problems I've solved**: real problems from my work and how I approached them.
5. **About** and **contact**.
